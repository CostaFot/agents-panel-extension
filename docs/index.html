Agents Panel for Command Palette

Your AI agents' usage — right inside Windows PowerToys Command Palette.

Agents Panel is an open-source PowerToys Command Palette extension that shows how much of your Claude, Codex, and GitHub Copilot usage quotas you have used, plus your recent opencode spend and token counts — session and weekly percentages, reset times, and plan info, with pinnable Dock quick-look buttons. It reads the sign-ins your machine already has and runs entirely locally — no telemetry, no analytics, no accounts of its own.
